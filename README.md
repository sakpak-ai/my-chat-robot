一、功能介绍
 
本项目基于 Streamlit 搭建可视化网页工具，实现多主流大模型接口统一调用与性能横向对比，支持 DeepSeek、智谱GLM4、通义千问三款大语言模型，核心功能如下：
 
1. 多模型多选调用：下拉多选框自由选择需要测试的大模型，批量发起对话请求；
2. 统一对话交互：文本输入框自定义提问内容，一次性获取多款模型回答并分块展示；
3. 性能指标自动统计：自动计算并记录每个模型的接口响应耗时、输出文本总字符数、每秒输出字符速度；
4. 可视化数据展示：以表格汇总全部性能指标，搭配柱状图直观对比各模型响应速度、输出速度；
5. 异常捕获提示：接口鉴权失败、网络超时、服务异常等场景自动捕获报错，页面展示失败原因。
 
二、实现思路
 
1. 模型配置统一封装：使用字典集中管理三款大模型的接口地址、密钥、模型名称，统一调用规范，便于新增/删减模型；
2. 接口请求通用函数：封装独立  call_ai_model  函数，统一处理 HTTP 请求、计时、返回结果解析、异常捕获，复用逻辑减少冗余代码；
3. 前端页面分层布局：采用 Streamlit 组件划分选择区、输入区、结果展示区、数据图表区，页面逻辑清晰；
4. 性能数据采集逻辑：发起请求前记录时间戳，接收完整回复后计算耗时，基于文本长度算出输出效率，存入指标字典；
5. 数据可视化处理：将指标列表转为 Pandas 表格，使用内置柱状图组件完成可视化对比；
6. 容错机制设计：全流程捕获请求异常，不中断整体程序运行，失败模型单独标注错误信息，不影响其他模型执行。
 
三、使用说明
 
1. 环境依赖安装
 
打开终端，执行依赖安装命令：
  
pip install streamlit requests pandas

2. 密钥配置
 
打开  4.py ，将三处 "此处替换密钥"分别替换为对应平台生成的 sk 格式 API Key；
 
3. 程序启动
 
终端切换到代码文件所在目录，运行启动指令：
 
streamlit run 4.py
 
4. 操作步骤
 
1. 在多选框勾选需要测试的AI模型，默认全选；
2. 在文本框输入想要提问的内容；
3. 点击「开始对比」按钮，程序自动批量调用接口；
4. 页面依次展示每个模型的回答内容；
5. 下方查看性能数据表格、响应时间柱状图、输出速度柱状图；
6. 若模型调用失败，对应模块会红色提示失败详情。
